# Код сайта «Масштаб»

Статичный многостраничный сайт на чистом HTML/CSS/JS (без сборки и зависимостей),
реализующий структуру и тексты из `../site-content/`.

## Страницы

- `index.html` — главная
- `services.html` — услуги
- `cases.html` — кейсы (7 реальных кейсов с цифрами)
- `about.html` — о компании
- `contacts.html` — контакты (форма без бэкенда, см. ниже)
- `blog.html` — блог (заглушка, тем ещё нет)

## Как посмотреть локально

```bash
cd site
python3 -m http.server 8000
# открыть http://localhost:8000/index.html
```

## Что нужно доделать перед реальной публикацией

1. **Логотип и фото** — сейчас логотип нарисован как простой SVG-плейсхолдер (буква
   «M» + оранжевая стрелка), а фото основателя — заглушки с подписью. Нужно заменить
   на реальные файлы из брендбука (в исходном экспорте Telegram сами файлы не были
   выгружены).
2. **Форма на `contacts.html`** — сейчас только клиентская валидация без реальной
   отправки. Нужно подключить приём заявок: email, вебхук CRM или сторонний сервис
   форм.
3. **Плейсхолдеры `[ЗАПОЛНИТЬ]`** — контакты, партнёрства с CRM-вендорами, биография
   основателя, темы блога — см. `../site-content/README.md` для полного списка.

## Перенос в Tilda

Сайт сделан как отдельный статичный проект, а не как набор блоков Tilda. Если нужно
разместить именно на Tilda:

- **Вариант А (проще):** держать этот сайт на обычном хостинге (Vercel/Netlify/Cloudflare
  Pages и т.п.) без Tilda.
- **Вариант Б:** перенести секции в Tilda через блок «HTML-код» (T123): каждую секцию
  из этого кода (шапка, hero, услуги и т.д.) вставить отдельным HTML-блоком, стили —
  через общий блок `<style>` в начале страницы.
- **Вариант В:** пересобрать вручную на стандартных блоках Tilda, используя тексты из
  `../site-content/` и `../site-content/style-guide.md` как референс.
