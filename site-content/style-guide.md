# Style guide — сводка для верстки в Tilda

Сведено из присланного брендбука.

## Цвета

| Назначение | HEX |
|---|---|
| Тёмно-синий (фон шапки/футера, заголовки) | `#0A1E3A` |
| Оранжевый (акцент, CTA, иконки) | `#FF6A00` |
| Белый | `#FFFFFF` |
| Светло-серый (фон секций/подложки карточек) | `#E6E9EF` |

Проверьте контраст текста кнопок на оранжевом фоне (белый текст на `#FF6A00`) на
соответствие WCAG AA перед публикацией — на мелком тексте кнопок контраст может быть
на грани нормы.

## Типографика

- Шрифт: Manrope (подключить через Google Fonts или загрузить в Tilda Fonts)
- Заголовки — Bold
- Основной текст — Regular

## Логотип

- Полный лок-ап (знак + «МАСШТАБ» + строка услуг «системы продаж • CRM • подбор
  персонала») — для шапки на десктопе, для документов и печатных материалов
- Знак отдельно (буква «М» со стрелкой) — для фавикона, мобильной шапки, аватаров
  в соцсетях

## Графические элементы

- Стрелка вверх — рост
- Гора с флагом — цель/маршрут (используется в блоке процесса, см. `01-homepage.md`)
- График роста
- Иконка людей — команда
- Мишень — фокус/цель
- Галочка — эффективность/готовность
- Диагональный паттерн из стрелок — использовать точечно как декоративный фон
  (например, hero или CTA-баннер на тёмно-синем), не перегружать им текстовые секции
  на светлом фоне
