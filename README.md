# Масштаб — контент и структура сайта на Tilda

Репозиторий используется для подготовки текстов, структуры блоков и сведённого брендбука
для сайта компании «Масштаб» (системы продаж, CRM, подбор персонала). Сайт создаётся
с нуля в конструкторе Tilda на основе присланного брендбука.

Tilda — no-code конструктор, сайт не хранится как код, поэтому здесь лежат не файлы сайта,
а материалы для ручной сборки в редакторе Tilda.

## Структура репозитория

- `site-content/README.md` — как пользоваться пакетом, что нужно доуточнить перед публикацией
- `site-content/style-guide.md` — цвета, шрифты, лого, графика (сведено из брендбука)
- `site-content/01-homepage.md` — главная страница, блок за блоком
- `site-content/02-services.md` — страница «Услуги»
- `site-content/03-cases.md` — страница «Кейсы»
- `site-content/04-about.md` — страница «О компании»
- `site-content/05-contacts.md` — страница «Контакты»
- `site-content/06-blog.md` — структура раздела «Блог»
