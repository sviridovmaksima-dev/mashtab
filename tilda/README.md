# Перенос сайта «Масштаб» в Tilda через HTML-блок

В отличие от `../site/` (отдельный самостоятельный сайт), файлы в этой папке
рассчитаны на вставку прямо в конструктор Tilda через блок «HTML-код» (T123),
без своего хостинга.

## Файлы

- `head-code.html` — общий CSS (переменные, кнопки, карточки, адаптив) и
  подключение шрифта Manrope. Вставляется **один раз** на весь проект.
- `home-blocks.html` — блоки главной страницы
- `services-blocks.html` — блоки страницы «Услуги»
- `cases-blocks.html` — блоки страницы «Кейсы» (7 кейсов отдельными блоками)
- `about-blocks.html` — блоки страницы «О компании»
- `contacts-blocks.html` — блоки страницы «Контакты»
- `blog-blocks.html` — блоки страницы «Блог»

Внутри каждого файла разделы отмечены комментариями
`<!-- ===== TILDA БЛОК: Название ===== -->` … `<!-- ===== КОНЕЦ БЛОКА ===== -->`.
Один такой раздел = содержимое одного блока T123 на странице Tilda.

## Шаг 1. Общий код (один раз на проект)

Настройки сайта → **Ещё** → **Вставить код** → «Вставить код в HEAD каждой
страницы сайта» → вставить туда всё содержимое `head-code.html`.

Так шрифт и стили подключатся сразу на всех страницах, и не придётся
дублировать CSS в каждом отдельном блоке.

## Шаг 2. Логотип и фото основателя

В переписке пришли сам файл иконки логотипа (буква «M» со стрелкой) и фото
Свиридова Максима — вставьте их через собственный загрузчик Tilda, а не
как base64 в коде (иначе каждый блок с картинкой будет весить лишние
сотни килобайт):

1. На любой странице добавьте временно пустой блок «Изображение».
2. Загрузите туда файл логотипа (или фото).
3. Кликните по загруженному изображению правой кнопкой → «Копировать
   ссылку на изображение» (или откройте его в новой вкладке и скопируйте
   адрес — Tilda раздаёт файлы с домена `static.tildacdn.com`).
4. Вставьте эту ссылку вместо `ЗАМЕНИТЬ_НА_ССЫЛКУ_ЛОГОТИПА` /
   `ЗАМЕНИТЬ_НА_ССЫЛКУ_ФОТО` во всех HTML-блоках, где они встречаются.
5. Удалите временный блок «Изображение».

Ссылка на логотип используется в шапке и футере каждой страницы — обновите
её везде (или один раз, если сделаете шапку/футер сайтовыми — см. ниже).

## Шаг 3. Добавление блоков на страницу

На нужной странице сайта: **+** (добавить блок) → вкладка **«Прочее»** →
блок **T123 «HTML-код»** → вставить содержимое одного раздела из файла
выше → сохранить. Повторить для каждого раздела, в том порядке, в котором
они идут в файле.

## Шапка и футер на всех страницах (рекомендация)

Шапка и футер повторяются в каждом файле — это сделано, чтобы можно было
собрать страницы независимо. Но проще сделать их **сайтовыми**: добавьте
блок шапки на любую страницу, откройте его настройки и включите опцию
«Сделать блок сайтовым» / «Header» (аналогично для футера внизу страницы —
«Footer»). Тогда шапка и футер появятся на всех страницах сайта
автоматически, и блоки «Шапка»/«Футер» из остальных файлов вставлять уже
не нужно — начинайте сразу со второго блока каждого файла.

## Форма на странице «Контакты»

Блок формы в `contacts-blocks.html` — только вёрстка, без реальной
отправки заявок (HTML-блок Tilda не имеет своего сервера для приёма
данных). Два варианта:

- Заменить блок на нативный блок Tilda «Форма» (T027 и похожие) —
  тогда заявки будут приходить в почту/Telegram/CRM Tilda как обычно;
  оформить его в цветах бренда можно через настройки блока
  (`#0A1E3A`, `#FF6A00` — см. `head-code.html`).
- Подключить свой обработчик (сторонний сервис форм или вебхук в CRM) и
  прописать его в форме вместо заглушки.
